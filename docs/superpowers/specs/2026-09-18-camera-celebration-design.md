# 인증샷 완료 축하 화면 설계

## 목표

연속 촬영이 완료되면 프레임 선택 UI를 퇴장시키고, 완성 사진을 왼쪽으로 이동해 오른쪽에 손을 흔드는 사자와 `즐거운 축제 되세요~!` 문구를 보여준다. 촬영 전·중·후 프레임 선택 가능 여부를 명확하게 제한한다.

## 상태별 동작

- `live`: 프레임 선택이 가능하다.
- `countdown`: 프레임 선택 버튼을 비활성화하며 레이아웃은 움직이지 않는다.
- `captured`: 프레임 선택 영역을 왼쪽 화면 밖으로 이동시키고 투명하게 만든다. 선택 영역 전체는 클릭과 포커스를 받을 수 없다.
- `captured` 진입과 동시에 완성 사진 및 하단 액션 버튼은 프레임 선택 영역이 있던 자리만큼 왼쪽으로 이동한다. 사진은 화면 밖으로 사라지지 않는다.
- `captured`에서 `다시 찍기`를 누르면 선택 영역, 사진, 액션 버튼이 원래 위치로 돌아오고 사자 축하 UI가 사라진다. 선택했던 프레임은 유지한다.

## 사자 축하 UI

사용자가 제공한 얼굴 PNG와 양손 PNG를 프로젝트 에셋으로 복사해 사용한다. 얼굴은 기존 사진 자리의 오른쪽 영역에 고정하고, 손 이미지는 얼굴 앞에 겹쳐 배치한다. 한 PNG 안에 좌우 손이 함께 있으므로 이미지 전체를 작은 각도로 좌우 회전시켜 손을 흔드는 효과를 만든다.

사자 위에는 `즐거운 축제 되세요~!` 문구를 표시한다. 사자와 문구는 사진 이동이 시작된 뒤 짧게 페이드·확대되어 나타나며, 손 흔들기 애니메이션은 계속 반복한다. `prefers-reduced-motion` 환경에서는 반복 회전을 중단하고 정적인 상태로 표시한다.

## 레이아웃과 전환

기존 1920×1080 고정 캔버스와 키오스크 스케일링을 유지한다. 완료 시 프레임 선택 영역은 현재 `left: 70px`, `width: 148px` 위치에서 왼쪽으로 충분히 퇴장한다. 사진 그룹은 선택 영역과의 간격을 포함한 고정 거리만큼 왼쪽으로 이동하며, 사자 축하 UI는 이동 전 사진이 차지하던 오른쪽 공간에 배치한다.

전환은 CSS 클래스 `camera__screen--captured`를 기준으로 처리해 React 상태와 시각 상태를 일치시킨다. 프레임 선택 영역에는 `aria-hidden`과 `tabIndex`/`disabled` 상태를 함께 적용한다.

- 백엔드, API 문서, 공유 프런트엔드 파일은 수정하지 않는다.

## 테스트

- 프레임 버튼은 `live`에서만 활성화되는지 검증한다.
- 완료 상태 클래스와 선택 영역 접근성 속성을 검증한다.
- 완료 시 사진 그룹은 왼쪽으로 이동하되 화면 밖으로 사라지지 않는 CSS인지 검증한다.
- 사자 얼굴·손 에셋과 문구가 `captured`에서만 렌더링되는지 검증한다.
- 손 흔들기 및 모션 감소 CSS를 검증한다.
- 재촬영 시 기존 상태 복원 로직을 유지하는지 검증한다.

## 완료 조건

세 프레임 모두 촬영 완료 후 동일한 축하 레이아웃으로 전환되고, 재촬영으로 원래 레이아웃이 복원되어야 한다. 전체 프런트엔드 테스트와 프로덕션 빌드가 통과하고 백엔드 변경이 없어야 한다.
