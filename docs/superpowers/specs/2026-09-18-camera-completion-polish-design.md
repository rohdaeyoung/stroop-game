# 촬영 완료 화면 마무리 인터랙션 설계

## 목표

촬영 완료 화면의 좌측 이동을 자연스럽게 맞추고, 폴라로이드 주변 배경을 제거하며, 주요 버튼에 명확한 클릭 피드백을 제공한다.

## 완료 화면 전환

- 완성 사진과 프레임 선택칸은 동시에 좌측 이동을 시작한다.
- 두 요소의 이동 시간은 `0.65초`, easing은 `cubic-bezier(0.22, 1, 0.36, 1)`로 통일한다.
- 프레임 선택칸의 투명도도 `0.65초`에 걸쳐 줄어들고, 이동이 끝난 뒤 숨김 처리한다.
- 모션 감소 설정에서는 전환 시간을 사실상 제거한다.

## 폴라로이드 배경

- 촬영 완료 상태에서 폴라로이드 카드 바깥에 보이는 검은 직사각형 배경을 투명하게 만든다.
- 촬영 사진과 흰색 폴라로이드 테두리 자체는 유지한다.
- 다른 프레임과 촬영 전 미리보기에는 영향을 주지 않는다.

## 완료 버튼

- `다시 찍기`, `다음 →` 버튼 묶음을 현재보다 `50px` 위로 올린다.
- 버튼은 계속 화면 가로 중앙에 유지한다.
- 누르는 동안 `scale(0.94)`로 축소하고 흰색 외곽 글로우와 내부 하이라이트를 표시한다.
- 클릭을 해제하면 약 `0.12초` 안에 원래 상태로 돌아온다.

## 랭킹 CTA 버튼

- `사진은 괜찮아요!`, `어흥샷 찍으러 가기`에도 완료 버튼과 같은 눌림 및 흰색 글로우 피드백을 적용한다.
- 키보드 탐색 시 흰색 `:focus-visible` 윤곽을 표시한다.

## 범위와 검증

- 프론트엔드 CSS와 회귀 테스트만 수정한다.
- JSX 동작, 라우팅, API 및 백엔드는 변경하지 않는다.
- 관련 회귀 테스트, 전체 프론트엔드 테스트, 프로덕션 빌드와 백엔드 무변경 여부를 확인한다.
