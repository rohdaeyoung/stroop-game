# 랭킹 CTA 버튼 클릭 피드백 설계

## 목표

랭킹 화면의 `사진은 괜찮아요!`와 `어흥샷 찍으러 가기` 버튼을 누르는 동안 흰색 글로우와 명확한 눌림 피드백을 제공한다.

## 디자인

- 기존 분홍색 배경과 평상시 그림자는 유지한다.
- 누르는 동안 버튼을 `scale(0.94)`로 축소한다.
- 같은 순간 흰색 외곽 글로우와 은은한 내부 흰색 하이라이트를 표시한다.
- `transform`과 `box-shadow`는 약 0.12초 동안 전환해 손을 떼면 자연스럽게 원래 상태로 돌아온다.
- 두 버튼이 공유하는 `.ranking__cta` 클래스에 동일하게 적용한다.
- 키보드 사용자는 `:focus-visible`에서 흰색 포커스 윤곽을 확인할 수 있어야 한다.
- 모션 감소 환경에서는 전환 시간을 사실상 제거한다.

## 범위

프론트엔드 CSS와 해당 회귀 테스트만 수정한다. JSX 동작, 라우팅, API 및 백엔드는 변경하지 않는다.

## 검증

- 회귀 테스트에서 기본 전환, 활성 상태의 축소 및 흰색 글로우, 키보드 포커스, 모션 감소 처리를 확인한다.
- 전체 프론트엔드 테스트와 프로덕션 빌드를 실행한다.
- Git diff로 백엔드 파일이 변경되지 않았음을 확인한다.
