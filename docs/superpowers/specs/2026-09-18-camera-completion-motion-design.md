# 촬영 완료 화면 모션·배치 개선 설계

## 목표

촬영 완료 순간 사진, 선택칸, 사자, 말풍선과 버튼이 하나의 연속된 흐름처럼 보이도록 전환 타이밍과 최종 배치를 정돈한다.

## 전환 순서

1. 촬영 완료 상태가 시작되면 사진과 프레임 선택칸이 동시에 왼쪽으로 이동한다.
2. 두 요소의 이동 시간은 기존과 동일한 `0.65초`이며 동일한 easing을 사용한다.
3. 이동 시작 후 `0.52초`가 지나면 사자와 말풍선이 함께 등장한다.
4. 사자는 과한 확대 없이 오른쪽에서 `30px`만 이동하며 나타난다.

이 순서는 사진과 선택칸이 자리를 비우기 전에 사자가 겹쳐 보이는 문제를 없애면서, 두 전환 사이에 긴 공백이 생기지 않게 한다.

## 최종 배치

- 사자 묶음을 현재보다 `60px` 위로 이동해 사진과 세로 중심을 맞춘다.
- 사자의 가로 위치와 크기는 현재 오른쪽 영역 안에서 유지한다.
- `다시 찍기`, `다음 →` 버튼 묶음을 현재보다 `35px` 더 위로 이동한다. 기존 `-50px`을 포함해 최종 이동량은 `-85px`이다.
- 버튼은 화면 가로 중앙을 유지한다.

## 손 흔들기

- 반복 시간은 `0.75초`에서 `1.1초`로 늘린다.
- 회전 범위는 `-5°~5°`에서 `-3°~3°`로 줄인다.
- 세로 흔들림은 `6px`에서 `3px`로 줄여 얼굴과 손의 결합이 흐트러지지 않게 한다.
- 모션 감소 설정에서는 기존처럼 애니메이션을 제거한다.

## 범위와 검증

- `frontend/src/features/ranking/Ranking.css`와 관련 정적 회귀 테스트만 수정한다.
- 촬영 로직, 프레임 합성, 라우팅, API와 백엔드는 변경하지 않는다.
- 타이밍, 이동량, 손 흔들기 값을 회귀 테스트로 고정한다.
- 전체 프론트엔드 테스트와 프로덕션 빌드를 실행한다.
