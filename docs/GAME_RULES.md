# 게임 규칙 (초안 — 민서님이 확정)

## 기본 룰
화면에 **색깔 이름 단어**가 뜨는데, 글자의 **실제 색**과 다를 수 있습니다.
플레이어는 질문에 맞는 답을 터치합니다.

- 모드 A: "글자의 **색**을 고르세요" (단어 뜻은 함정)
- 모드 B: "단어의 **뜻**을 고르세요" (글자 색이 함정)

## 점수
```
기본 정답     = 100점
콤보 보너스   = 100 × (1 + 콤보수 × 0.1)   // 10콤보면 2배
속도 보너스   = 남은시간(ms) / 10          // 빨리 누를수록 +
오답          = -50점, 콤보 리셋
```

## 난이도 가속
| 정답 수 | 제한시간 | 선택지 수 |
|---|---|---|
| 0 ~ 9   | 3.0초 | 3개 |
| 10 ~ 19 | 2.4초 | 4개 |
| 20 ~ 29 | 1.8초 | 4개 |
| 30 ~ 39 | 1.4초 | 5개 |
| 40+     | 1.1초 | 5개 |

## 종료 조건
- 제한시간 내 미응답 → 게임 오버
- 오답 3회 누적 → 게임 오버
- 총 플레이 60초 경과 → 게임 오버
