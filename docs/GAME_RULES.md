## 기본 룰

화면에 **색깔 이름 단어**가 뜨고, 글자의 **실제 색은 단어 뜻과 항상 다릅니다.**
플레이어는 질문에 맞는 답을 터치합니다.

| 모드 | 질문 | 함정 | 출제 비율 |
|---|---|---|---|
| A `COLOR` | "글자의 **색**을 고르세요" | 단어 뜻 | **70%** |
| B `WORD` | "단어의 **뜻**을 고르세요" | 글자 색 | **30%** |

- 모드는 **매 문제마다 랜덤**으로 정합니다.

## 색

**5개** — 빨강 `red` · 파랑 `blue` · 초록 `green` · 노랑 `yellow` · 보라 `purple`

- 코드: `frontend/src/shared/constants/colors.js`
- 선택지가 최대 5개이므로 색은 5개보다 줄이면 안 됩니다.

## 점수

```
정답 1회   = 100 × (1 + 콤보수 × 0.1)  +  남은시간(ms) / 10     → 반올림
오답 1회   = -50점, 콤보 0 으로 초기화
```

- **콤보수**는 이번 정답 직전까지의 연속 정답 수입니다. 첫 정답은 콤보 0 → 100점 + 속도 보너스.
- 10콤보면 콤보 부분이 2배(200점)가 됩니다.
- **점수는 0 아래로 내려가지 않습니다.** (30점일 때 오답 → 0점)
- 코드: `frontend/src/features/game/scoreCalculator.js`

## 난이도 가속

| 정답 수 | 제한시간 | 선택지 수 |
|---|---|---|
| 0 ~ 9   | 3.0초 | 3개 |
| 10 ~ 19 | 2.4초 | 4개 |
| 20 ~ 29 | 1.8초 | 4개 |
| 30 ~ 39 | 1.4초 | 5개 |
| 40+     | 1.1초 | 5개 |

- 코드: `frontend/src/features/game/difficulty.js`

## 종료 조건

하나라도 해당하면 게임 오버입니다.

- 제한시간 내 미응답
- 오답 3회 누적
- 총 플레이 60초 경과

## 성공 / 실패

| 결과 | 조건 |
|---|---|
| **성공** | 최종 점수 **10,000점 이상** |
| 실패 | 10,000점 미만 |

- 결과 화면에서 판정합니다. 성공 여부는 서버에 보내지 않으며 API 는 바뀌지 않습니다.

## 서버 검증

`POST /api/scores` 요청이 아래 범위를 벗어나면 서버가 저장하지 않고 **400** 으로 거부합니다.

| 필드 | 허용 범위 | 벗어나면 | 이유 |
|---|---|---|---|
| `nickname` | 1 ~ 10자, **한글·영문·숫자만** | `INVALID_NICKNAME` | 공개 랭킹에 노출되는 값 |
| `score` | **0 ~ 300,000** | `INVALID_SCORE` | 비정상 점수 차단 |
| `wrongCount` | **0 ~ 3** | `INVALID_SCORE` | 오답 3회에서 게임 오버 |
| `correctCount`, `maxCombo` | 0 이상 | `INVALID_SCORE` | |
| `playTimeMs` | **0 ~ 70,000** | `INVALID_SCORE` | 60초 게임 + 여유 10초 |

> 조작을 막기 위한 장치가 아니라 **앱 버그로 이상한 값이 저장되는 것을 막는 안전망**입니다.

**닉네임 문자 규칙** — 정규식 `^[가-힣ㄱ-ㅎㅏ-ㅣa-zA-Z0-9]+$`

- 공백, 특수문자(`!` `_` `<` 등), 이모지는 허용하지 않습니다
- 자음·모음만 쓴 닉네임(`ㅋㅋ`)은 한글로 보고 허용합니다
- 닉네임 입력 화면도 **같은 정규식**으로 미리 막아주세요. 서버에서 거부되면 참가자가 다시 입력해야 합니다
- 코드: `backend/src/main/java/com/stroop/api/score/ScoreRules.java`
