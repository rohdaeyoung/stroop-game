## 기본 룰

화면에 **색깔 이름 단어**가 뜨고, 글자의 **실제 색은 단어 뜻과 항상 다릅니다.**
플레이어는 질문에 맞는 답을 터치합니다.

| 모드 | 질문 | 함정 | 출제 비율 |
|---|---|---|---|
| A `COLOR` | "글자의 **색**을 고르세요" | 단어 뜻 | **70%** |
| B `WORD` | "단어의 **뜻**을 고르세요" | 글자 색 | **30%** |

- 모드는 **매 문제마다 랜덤**으로 정합니다.

## 색

**4개** — 빨강 `red` · 파랑 `blue` · 노랑 `yellow` · 초록 `green`

- 코드: `frontend/src/shared/constants/colors.js`
- 선택지는 항상 네 색상을 모두 보여줍니다.

## 점수

```
정답 1회   = 100 × (1 + 콤보수 × 0.1)  +  남은시간(ms) / 10     → 반올림
오답 1회   = -50점, 콤보 0 으로 초기화
```

- **콤보수**는 이번 정답 직전까지의 연속 정답 수입니다. 첫 정답은 콤보 0 → 100점 + 속도 보너스.
- 10콤보면 콤보 부분이 2배(200점)가 됩니다.
- **점수는 0 아래로 내려가지 않습니다.** (30점일 때 오답 → 0점)
- 코드: `frontend/src/features/game/scoreCalculator.js`

## 종료 조건

하나라도 해당하면 게임 오버입니다.

- **오답·미응답 합쳐 3회 누적**
- 총 플레이 30초 경과

### 미응답 처리

제한시간 안에 고르지 못하면 **목숨 1개만 차감**하고 다음 문제로 넘어갑니다.

- 예전에는 한 번만 놓쳐도 바로 끝났습니다. 초반 제한시간이 3초라 처음 해보는
  참가자가 문제를 읽다가 그대로 종료되는 일이 많았습니다.
- **점수는 깎지 않습니다.** 찍어서 틀린 것(-50)과 아예 못 고른 것을 같게
  벌하지는 않습니다.

| | 점수 | 목숨 | 콤보 |
|---|---|---|---|
| 오답 | **-50** | -1 | 초기화 |
| 미응답 | 그대로 | -1 | 초기화 |

## 성공 / 실패

| 결과 | 조건 |
|---|---|
| **성공** | 최종 점수 **5,000점 이상** |
| 실패 | 5,000점 미만 |

- 결과 화면에서 판정합니다. 성공 여부는 서버에 보내지 않으며 API 는 바뀌지 않습니다.

### 5,000점으로 정한 이유

전체 플레이 시간이 60초에서 30초로 줄면서(#52) 기존 기준 10,000점은 사실상 달성이
불가능해졌습니다. 점수 공식과 난이도 표로 시뮬레이션한 결과입니다. (#56)

| 플레이 | 30초 점수 |
|---|---|
| 실수 없음 · 문제당 0.8초 | 15,580 |
| 실수 없음 · 문제당 1.0초 | 11,550 |
| **잘함** · 1.0초 · 8문제마다 오답 | **6,060** |
| 보통 · 1.3초 · 5문제마다 오답 | 3,150 |

10,000점을 넘으려면 30초 내내 한 번도 틀리지 않고 문제당 1초 안에 답해야 합니다.
부스를 처음 찾은 참가자 대부분이 실패로 끝나게 됩니다.

5,000점은 **"잘함" 수준이면 성공**하는 기준입니다.

## 서버 검증

`POST /api/scores` 요청이 아래 범위를 벗어나면 서버가 저장하지 않고 **400** 으로 거부합니다.

| 필드 | 허용 범위 | 벗어나면 | 이유 |
|---|---|---|---|
| `nickname` | 1 ~ 10자, **한글·영문·숫자만** | `INVALID_NICKNAME` | 공개 랭킹에 노출되는 값 |
| `score` | **0 ~ 300,000** | `INVALID_SCORE` | 비정상 점수 차단 |
| `wrongCount` | **0 ~ 3** | `INVALID_SCORE` | 오답 3회에서 게임 오버 |
| `correctCount`, `maxCombo` | 0 이상 | `INVALID_SCORE` | |
| `playTimeMs` | **0 ~ 40,000** | `INVALID_SCORE` | 30초 게임 + 여유 10초 |

> 조작을 막기 위한 장치가 아니라 **앱 버그로 이상한 값이 저장되는 것을 막는 안전망**입니다.

**닉네임 문자 규칙** — 정규식 `^[가-힣a-zA-Z0-9]+$` (길이 1~10자는 별도 검사)

- 공백, 특수문자(`!` `_` `<` 등), 이모지는 허용하지 않습니다
- 자음·모음(`ㅋㅋ`, `대ㅎ`)은 허용하지 않습니다 — 완성된 한글만 받습니다
- 닉네임 입력 화면도 **같은 정규식**으로 미리 막아주세요. 서버에서 거부되면 참가자가 다시 입력해야 합니다
- 코드: 서버 `backend/src/main/java/com/stroop/api/score/ScoreRules.java`, FE `frontend/src/features/onboarding/nicknameStorage.js`
